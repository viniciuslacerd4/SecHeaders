# SecHeaders — monograma profissional

Final production asset: `public/brand/secheaders-monogram.svg`.
PNG export for sharing: `public/brand/secheaders-monogram.png`.

The concept was explored with the built-in ImageGen tool. The selected orthogonal bracket concept was reconstructed as clean vector paths for reliable small-size rendering. The final vector is monochrome, transparent, and has no raster texture or metallic effects.

## Final exploration prompt

Create a crisp 2D corporate software logo icon. This is a NEW design direction: a SQUARE ORTHOGONAL abstract monogram built ONLY with horizontal and vertical strokes and tiny rounded 90-degree corners. Absolutely NO diagonal strokes and NO hexagonal contour. Two opposing interlocking square brackets suggest an S through precisely arranged negative space: upper bracket opens right, lower bracket opens left, linked visually at center. Compact balanced geometric symbol, akin to a highly refined enterprise developer-tool identity. Use only one solid off-white color #ECECEA. Constant stroke thickness, clean smooth immaculate edges. No texture or grain anywhere. No noise, no speckles, no residue in empty areas. The entire background and all empty holes must be 100% transparent clean alpha. No shading, no gradients, no 3D, no lighting, no drop shadow, no shield, no badge. Single simple symbol centered in square image, occupying 70% of frame. No words or text. Design must be reproducible as a tiny monochrome vector mark for a professional SecHeaders web security product.
